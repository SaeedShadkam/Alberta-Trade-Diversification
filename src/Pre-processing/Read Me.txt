0- Alberta_Data_Retriever.py
	0.1 Save the .json mapping for duplicated UNComTrade Country Codes
	0.2 Downloads Alberta and Canada Trade Data from StatCan
	0.3 Adjusts Alberta trade data based on the proportion of the Canada trade data based on CEPII to StatCan
	0.4 Adds the Alberta trade data with code 9999 to the CEPII files
	0.5 IMPORTANT NOTE: Comtrade and World Bank consider Taiwan as part of China, in order to keep the consistency of our method as much as possible, for Alberta trade data retrieved from the StatCan, I combine the trades with Taiwan to trades with China.
	0.6 The outputs are the folders in the CEPII file, with names following the pattern: 'BACI_HS12_Y{year}_{model_parameters['CEPII_Version']}_alberta'

1- Process_CEPII.jl
	1.1 Reads BACI files. Calculates desired variables like TotalExportofCmdbyPartner, TotalExportbyPartner, WorldExportofCmd, 								WorldTotalExport, 	AvgUnitPriceofExporterToWorld, ...
	1.2 Calculate the related measures like Theil Concentration Index, RCA, Trade_Complementarity, HS4 basket complimentarity
	1.3 Includes Alberta's Potential Trades for 2024 (Only the last year) to be used in prediction phase
	1.4 Output file is: "CEPII_Processed_HS4_$(starting_year)$(end_year).csv" in the CEPII Folder
	
2- country_cmd_policy.py
	2.1 Inputs to this file are: a) Trade_Policies_GTA.csv, b) country_list.csv, c) 1- CEPII_Processed_HS4_$(starting_year)$(end_year).csv
	2.2 It processes downloaded Trade_Policies_GTA file to act as an input in the Matching_Tables.jl code
	2.3 The output is called 'country_cmd_policy.csv'

3- Process_Tariff.py
	3.1 This script combines the Preferred Tariff Rate table with the MFN (Most Favored Nation) tariff rates table.
	3.2 Note that in the Preferred Rate table, the "Partner" can be either a region from RegionCodeDescription.csv or a specific country code.
	3.3 The final output is generated by performing a left join of the Preferred Tariff Rate table with the MFN table.
	3.4 Consequently, some trade flows may be missing in this table (specifically, trade flows for which there is no Preferred Rate). This should be accounted for when merging with other tables in the next step.
	3.5 The output file is  ".csv".


4- Matching_Tables.jl
	4.1 Filters the countries to TOP30 according to the country_list.csv
	4.2 Adds Commodity_policty and Country Distance and Macro_var .csv to the CEPII_Processed (Trade data) from previous code
	4.3 Output file is: "Diversification_Project_Raw.csv"
